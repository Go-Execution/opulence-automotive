# Opulence Automotive Productions LLC

Single-page luxury automotive, custom parts, and capsule apparel storefront built for **Opulence Automotive Productions LLC.** (`OP-01 Black Sovereign`).

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Motion (`motion/react`)
- Phosphor Icons (`@phosphor-icons/react`)
- Self-hosted `@fontsource` typography (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`)

## Local Development
```bash
npm install
npm run dev
```

## Verification
```bash
npm run build
npm run lint
```
